# コミカル・ドッジバトル

Windowsパソコンのブラウザで遊べる、斜め見下ろし型の2Dドッジボールアクションゲームです。HTML、CSS、JavaScriptとCanvas APIだけで作っています。

## 起動方法

1. このフォルダの `index.html` をブラウザで開きます。
2. モードとチームを選び、`C` キーまたはゲームコントローラーのボタン2で決定します。

サーバーは不要です。

## 操作方法

### キーボード

| 操作 | キー |
| --- | --- |
| 移動 / 照準 | WASD または 矢印キー |
| パス | Space |
| 決定 / シュート / キャッチ | C |
| ボタン3: ジャンプ | J |
| 向きを固定したまま移動 | Fを押しながら移動 |
| しゃがみ回避 | V |
| ダッシュ | 方向キーまたはWASDを同じ方向に二度押し / Shift |
| ポーズ | Escape |

### ゲームコントローラー

| 操作 | ボタン |
| --- | --- |
| 移動 / 照準 | 左スティック または 方向キー |
| 操作キャラ変更 | 右スティック |
| パス | ゲームパッド番号1 |
| 決定 / シュート / キャッチ | ゲームパッド番号2 |
| ボタン3: ジャンプ | ゲームパッド番号3 |
| 向きを固定したまま移動 | ゲームパッド番号4を押しながら移動 |
| しゃがみ回避 | ゲームパッド番号1（相手ボール時） |
| ダッシュ | 左スティックを同じ方向に二度押し / ゲームパッド番号5を押しながら移動 |
| ポーズ | STARTボタン |

コントローラーのボタン番号は `input.js` の `gamepadMap` で変更できます。

## 新しいルール

- 両チームとも、コート内に5人、コート外に3人います。
- コート内の5人にはHPがあり、キャラクターの頭上にHPバーが表示されます。
- コート外のキャラクターは外野役です。HPバーは表示されません。
- 全選手にスタミナがあり、内野はHPバーの下、外野は頭上に水色のスタミナバーが表示されます。
- シュート、回避、ダッシュでスタミナを消費し、消費動作を止めてしばらくすると自然回復します。
- 移動方向に応じてキャラクターが上下左右を向きます。ボタン4を押している間は向きを変えずに移動できます。
- 歩行中とダッシュ中は、ボールを持っている場合も両足が動きます。ダッシュは通常移動の3.2倍速です。
- 方向転換は入力へ即座に追従します。ゼンマイギアーズのみ、操作感を遅らせず見た目が段階的に追従します。
- ジャンプ力は初期版の1.5倍です。
- 2人プレイでも全選手を確認しやすいように、左右と上下の外野を含むコート全体を常に一画面へ表示します。
- ボールが落ちているときは、自チーム内野のうちボールに近いキャラクターへ操作カーソルが自動で切り替わります。
- 右スティックを倒すと、その方向にいる自チーム内野へ操作キャラクターを切り替えます。
- ジャンプ中でもシュートやパスができます。
- 敵のシュートをキャッチすると「CATCH」と表示されます。誤投球防止の0.2秒後から0.55秒以内にシュートボタンを押し直すと、スタミナ22を使って元の投手へ「COUNTER!」を返します。
- シュートキャッチは乱数を使わず、ボタンを押した時点でシュート種別、テクニック、向き、飛距離、威力から受付時間を決定します。その時間内にボールが捕球範囲へ入れば成功し、特殊シュートほど受付時間が短くなります。
- ボールの取得資格は落下地点の陣地で決まります。内野の球はその内野チーム、外野の球はその外野チームだけが取得でき、捕球範囲が境界線を越えても相手陣地の球は取れません。
- 外野は上下・横のエリアを角通路で行き来でき、外周側にも広く移動できます。外野球を通常回収できない場合は最長3秒で正しいチームの最寄り外野手へ渡し、試合を自動的に再開します。
- カウンター時、元の投手が内野ならその投手へ返します。元の投手が外野なら敵内野へ切り替え、左スティック入力時はその方向の内野、入力がない場合は外野投手への返球線に近い内野を狙います。
- カウンター時は短い瞬間停止、青白い円陣と金色の集光、腕の残像、四層の光跡、命中時の十字閃光と土煙が表示されます。強いシュートを返すほど光量が増えますが、性能は変化しません。
- トリプルショットは通常球の1.3倍の本体と、従来比1.3倍の追加球へ分裂し、3色の編み込み状の光跡を残します。命中時は本体に三重衝撃波、追加球に星形の火花が表示されます。
- LIGHTNINGは最初に狙った地点を通過しても消えず、大きなジグザグ軌道のまま画面外周まで飛びます。
- 特殊シュートは命中すると相手を吹き飛ばしてその場でエフェクトが終了します。IRONと張り手シュートだけは貫通し、直進を続けて別の内野手にも命中します。
- バナナシュートは黄金色の曲線光跡と残像を残し、Uターン時に巨大な三日月と確定地点の照準を表示します。命中時は三日月型の斬撃が発生します。
- ゼンマイギアーズはHPが30％以下になると赤目の「オーバードライブ」状態になります。移動・ジャンプ・CPU反応・投球速度・回避判断が強化され、強い球への無謀なキャッチと長いパス回しを控えます。
- オーバードライブ中は、機体の周囲に火花、蒸気、移動方向と反対へ流れる赤い残像が表示されます。
- ロックオン・ロケットが誘導終了後にコート外へ外れた場合は、攻撃側の外野が回収して試合を再開します。
- シュートでダメージを受けた選手は0.55秒間操作不能になり、その間は移動、各種アクション、キャッチ、落ちたボールの自動拾得ができません。吹き飛ばしと空中からの落下は継続します。
- 相手チームの内野を全員倒すと勝利、自チームの内野を全員倒されると敗北です。

## ボタンの意味

自チームがボールを持っている場合:

| ボタン | 動作 |
| --- | --- |
| ボタン0 | 味方へパス |
| ボタン2 | 相手へシュート |
| ボタン3 | ボール保持者がジャンプ |
| ボタン1 | 深くかがむ回避 |

相手チームがボールを持っている場合:

| ボタン | 動作 |
| --- | --- |
| ボタン2 | 操作キャラがキャッチ構え |
| ボタン3 | 操作キャラがジャンプ |
| ボタン1 | 深くかがむ回避 |

パスとシュートは、ボタンを押した瞬間の左スティックまたは方向キーの向きにいるターゲットを自動で選びます。方向入力がない場合は、基本的に相手方向または近い味方を狙います。

ボール保持中は、パス候補の味方にPマークがつきます。方向入力なしでボタン0を押すとPマークの味方へパスします。方向入力をしながらボタン0を押すと、上・下・右の指定ポジションへPマークが切り替わり、そのまま即パスします。

## ファイルの役割

| ファイル | 内容 |
| --- | --- |
| `index.html` | Canvasと各JavaScriptファイルの読み込み |
| `style.css` | 画面全体のレイアウトと16:9表示 |
| `game.js` | ゲーム状態、斜め見下ろしコート、固定全体表示、複数キャラ管理、勝敗処理 |
| `player.js` | キャラクターのデータ、移動、ジャンプ、被弾、頭上HP、描画 |
| `ball.js` | ボールの保持、パス、シュート、落下、跳ね返り |
| `cpu.js` | CPUチームの移動、投球、パス、回避、キャッチ判断 |
| `input.js` | キーボードとGamepad APIの入力管理 |
| `assets/characters/` | 青チーム・赤チームの金髪少年スプライト素材 |

## 開発メモ

- 内部解像度は1440×720です。
- コートは旧版より横1.5倍、縦1.2倍の世界座標で管理しています。
- `game.js` の先頭にある `DEBUG_MODE` を `true` にすると、当たり判定や移動可能範囲を表示できます。
- キャラクターは8ポーズのPNGスプライトを使用し、待機、歩行、ダッシュ、ジャンプ、投球、キャッチを状態に応じて切り替えます。足元を基準にしているため、Godotの`AnimatedSprite2D`へ移す場合も位置を合わせやすい構成です。
- 必殺シュート、キャラクター選択、2人対戦などは、現在のチーム配列と入力処理を拡張して追加できます。
